# Organización del proyecto con SCRUM

Hemos utilizado Trello para planificar y realizar el seguimiento de las tareas del proyecto mediante la metodología SCRUM.

El primer día celebramos una reunión *Daily Scrum* para distribuir las tareas entre los miembros del equipo.
